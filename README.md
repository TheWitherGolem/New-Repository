# Aloud

Highlight text in any application, press a hotkey, hear it read out.

Aloud sits in the Windows tray doing nothing until you press its hotkey. It
then copies whatever you have selected, wherever you are — a browser, a PDF, an
IDE, a chat window, an email — and reads it in a voice you have chosen and
tuned. Another hotkey brings its window to the front so you can change the
voice, the accent, the speed, the pitch or the phrasing without leaving what you
were doing.

Voices run locally. After the first download nothing leaves your machine and
nothing needs an internet connection.

## Installing

First install 64-bit Python 3.10 or newer from
[python.org](https://www.python.org/downloads/windows/). **Tick "Add python.exe
to PATH"** on the first screen of its installer — Aloud cannot find Python
without it.

Then double-click **`Install.bat`** in this folder and wait. It builds a `.venv`
beside itself, installs the dependencies into it, and downloads a first voice.
Nothing is installed system-wide and no administrator rights are needed.

If you would rather drive it yourself, `Install.bat` is only a wrapper around:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

Useful variations:

```powershell
# Start with a Scottish voice instead of the default American one
powershell -ExecutionPolicy Bypass -File install.ps1 -Voice en_GB-alba-medium

# Skip the voice download and pick one from the app's Voices tab instead
powershell -ExecutionPolicy Bypass -File install.ps1 -Voice none

# Also launch Aloud whenever you log in
powershell -ExecutionPolicy Bypass -File install.ps1 -Startup
```

## Running it

Double-click **`Aloud.vbs`**. Nothing visibly happens — that is the point. It is
now in the tray, and the hotkeys are live.

**`Aloud-debug.bat`** does the same thing with a console and verbose logging,
for when something is misbehaving.

## The hotkeys

| Hotkey | What it does |
| --- | --- |
| `Ctrl + Alt + S` | Read whatever is highlighted, in any application |
| `Ctrl + Alt + X` | Stop |
| `Ctrl + Alt + P` | Pause / resume |
| `Ctrl + Alt + Space` | Show or hide the control window |

All four are rebindable on the Settings tab. Type combinations like
`ctrl+shift+f9` or `win+alt+space`; each one needs at least one modifier, since
a bare key would be swallowed from every other application on the machine.

If nothing is selected when you press the read hotkey, Aloud reads your
clipboard instead. You can turn that off.

## Shaping how it sounds

Everything on the Speak tab applies live to the next thing you read.
Double-click any slider to put it back to its default.

| Control | Range | What it changes |
| --- | --- | --- |
| **Voice** | — | Which model speaks, and therefore the accent |
| **Speaker** | model-dependent | For multi-speaker models, which of its voices to use |
| **Speed** | 0.5 – 2.5 | How fast it talks |
| **Pitch** | 0.7 – 1.4 | Higher or lower voice, *without* changing the speed |
| **Volume** | 0 – 200% | Output level |
| **Expression** | 0 – 1.5 | Variation in pitch and energy. Low is flat and newsreaderly; high is animated |
| **Cadence** | 0 – 2 | Variation in timing. Low is metronomic; high has a looser, more natural rhythm |
| **Sentence pause** | 0 – 2s | Silence inserted between sentences |

Any combination can be saved as a named **preset** and recalled from the
dropdown — a fast flat one for skimming, a slow expressive one for reading
properly.

### Accents

Accent comes from the voice model. The Voices tab lists everything available and
downloads what you pick; each is 20–120 MB and works offline afterwards.

Some highlights:

- `en_GB-alba-medium` — Scottish
- `en_GB-northern_english_male-medium` — Northern English
- `en_GB-alan-medium`, `en_GB-jenny_dioco-medium` — Southern English
- `en_US-amy-medium`, `en_US-ryan-high` — American
- `en_GB-vctk-medium` — **109 British speakers in one model**, covering Scottish,
  Irish, Welsh, Northern and Southern English. Install it once and move between
  accents with the Speaker control.
- `en_US-libritts_r-medium` — 904 American speakers in one model.

The list is not limited to English; the Voices tab shows every language Piper
publishes.

## How it works

```
hotkey  →  copy the selection  →  clean the text  →  synthesise  →  play
```

- **The hotkeys** use `RegisterHotKey`, which needs no elevation and installs no
  keyboard hook — nothing that logs your typing, and nothing antivirus objects
  to.
- **The selection** is read the only way Windows allows for arbitrary
  applications: a synthetic `Ctrl+C`, then the clipboard. Aloud releases the
  modifier keys you are still holding before sending it (otherwise the target
  app sees `Ctrl+Alt+C` and ignores it), and puts your clipboard back
  afterwards.
- **The text** is tidied first — PDF hyphenation rejoined, hard wrapping
  unwrapped, invisible characters stripped — because a synthesiser stumbles
  audibly over all three.
- **Speech** is generated by [Piper](https://github.com/OHF-Voice/piper1-gpl), a
  local neural synthesiser, one sentence at a time so that a long article starts
  talking immediately instead of after it has all been rendered.
- **Pitch** is shifted by resampling the finished audio. That changes duration
  too, so Aloud synthesises at a compensating speed to cancel it out — which is
  why the pitch slider does not also make things faster.

### A note on the speed slider

Piper quantises each phoneme's duration to whole frames, so its speed control is
not proportional: asking for double speed the naive way gets you about 1.5x.
Aloud calibrates for this, and the slider goes to 2.5x, so any speed you want is
reachable — but treat the number as a dial rather than a precise multiplier. It
is accurate near 1x and increasingly approximate towards the ends.

### If Piper is not available

Aloud falls back to the voices Windows already has, so it can talk on first run
while a model is still downloading. They sound robotic next to Piper, but every
control except Expression and Cadence works the same way. Select it any time
from the Engine dropdown.

## Troubleshooting

**A hotkey does nothing.** Another application has claimed it. The Settings tab
says so when it cannot register one — pick a different combination.

**Nothing is read from one particular app.** If that app runs as administrator
and Aloud does not, Windows blocks the synthetic `Ctrl+C` — this is a security
boundary, not a bug. Either run Aloud elevated too, or copy manually and press
the hotkey with nothing selected.

**No sound.** Check the status bar at the bottom of the window; it reports
missing audio devices and missing voices explicitly. `Aloud-debug.bat` shows the
full log, which is also written to
`%LOCALAPPDATA%\Aloud\aloud.log`.

**It reads the wrong thing.** Some applications are slow to service a copy. The
selection is what got copied within about 0.7 seconds; in a very large document
try selecting a smaller passage.

## Where things live

| | |
| --- | --- |
| Settings and presets | `%APPDATA%\Aloud\config.json` |
| Voice models | `%LOCALAPPDATA%\Aloud\voices\` |
| Log | `%LOCALAPPDATA%\Aloud\aloud.log` |

Deleting the config file resets everything to defaults.

## Development

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest
```

The suite covers text cleanup, the DSP, settings, hotkey parsing, the voice
catalog and downloader, both engines, the window, and the full synthesis
pipeline — the last with a fake sound card, so it runs anywhere. The window
tests skip themselves where there is no display.

Layout:

```
aloud/
  app.py        wiring: hotkeys, tray, window, speech
  ui.py         the control window
  tray.py       the tray icon
  hotkeys.py    RegisterHotKey and its message loop
  selection.py  reading the highlighted text
  winapi.py     the ctypes layer, kept in one place
  speech.py     synthesis feeding playback
  audio.py      the output stream
  dsp.py        resampling, gain, trimming
  textproc.py   turning a raw selection into speakable prose
  voices.py     the voice catalog and downloader
  config.py     settings and presets
  engines/      piper (neural) and sapi (built-in Windows voices)
```
